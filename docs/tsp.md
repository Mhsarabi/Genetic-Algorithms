# Traveling Salesperson Problem (TSP) Using Genetic Algorithm

## 1. Problem Description

The Traveling Salesperson Problem (TSP) is a well-known combinatorial optimization problem.

The goal is to find the shortest possible route that:

- Visits every city exactly once.
- Returns to the starting city.
- Minimizes the total travel distance.

In this implementation, each city is represented by a two-dimensional coordinate (X, Y) on a plane.

The algorithm attempts to find a short route connecting all generated cities.

## 2. Genetic Algorithm Approach

A Genetic Algorithm (GA) is used to search for a near-optimal route.

Each individual represents a possible order in which the cities are visited.

### 2.1. City Generation

Cities are randomly generated within a 1000 × 1000 area.

Each city has two coordinates:

- X: Horizontal position.
- Y: Vertical position.

Duplicate coordinates are not allowed.

### 2.2. Chromosome Representation

Each chromosome represents a possible route through all cities.

It is a list containing city indices in a random order, followed by a fitness placeholder.

For example:

`[3, 1, 4, 0, 2, None]`

This chromosome represents a route that visits cities in the following order:

City 3 → City 1 → City 4 → City 0 → City 2

The last element (`None`) is reserved for storing the route distance.

Every city appears exactly once in each chromosome because the initial population is generated by shuffling a list of city indices.

### 2.3. Initial Population

The initial population consists of randomly generated routes.

For each individual:

1. A list of city indices is created.
2. The list is randomly shuffled.
3. A `None` value is appended as a placeholder for the fitness value.

### 2.4. Crossover

The current implementation copies the first `p` individuals and appends these copies to the population.

These copies are used as offspring for the next mutation step.

**Note:** This implementation does not perform a traditional genetic crossover between two parent chromosomes. It uses parent copying followed by mutation.

### 2.5. Mutation

Mutation modifies the offspring by swapping the positions of two randomly selected cities.

For each offspring:

1. Two different positions are randomly selected.
2. The cities at those positions are swapped.

This operation changes the visiting order while preserving the validity of the route.

### 2.6. Fitness Function

The fitness function calculates the total Euclidean distance of a route.

The Euclidean distance between two cities is calculated using:

`d = sqrt((x2 - x1)^2 + (y2 - y1)^2)`

The total route distance is the sum of distances between consecutive cities.

The starting city is appended to the end of the route to ensure that the salesperson returns to the starting point.

**Lower fitness values represent better solutions**, because the objective is to minimize the total travel distance.

### 2.7. Selection

After calculating the fitness values, the population is sorted in ascending order based on route distance.

Only the best `population_size` individuals are retained for the next generation.

This ensures that shorter routes have a higher chance of surviving into subsequent generations.

## 3. Visualization

The implementation uses OpenCV and Matplotlib to visualize the cities and the best route.

- Cities are displayed as circles.
- The best route is displayed as connected lines.
- The final route returns to its starting city.

## 4. Algorithm Parameters

| Parameter | Value | Description |
|---|---:|---|
| Number of Cities | 200 | Total number of cities |
| Area Width | 1000 | Width of the coordinate area |
| Area Height | 1000 | Height of the coordinate area |
| Population Size | 100 | Number of individuals in each generation |
| Maximum Epochs | 200 | Maximum number of generations |

## 5. Dependencies

The following libraries are required:

- NumPy
- Matplotlib
- OpenCV

Install all dependencies using:

```bash
pip install -r requirements.txt
```

## 6. Execution

Run the following command from the project root:

```bash
python TSP/main.py
```

The algorithm evolves the population for the specified number of generations.

After execution, the program prints the best route found and displays its visualization.

## 7. Output

The output includes:

- The best route found by the algorithm.
- The total distance of that route.
- A graphical representation of the cities and the final route.
